# Book strategy plugins

`get_strategy(id)` returns one `StrategySpec`; call its `signal(view, params)` for a finite Series indexed in `view.roots` order. It validates configured parameters and universe. Defaults are bounded example menus, not hard-coded admissible values: custom values/ranges are expanded by the batch runner and frozen before evaluation. These modules never acquire data, import scratch code, execute trades or choose validation winners.

`CausalMarketView` supplies `decision_at`, `information_asof`, `roots`, `point_changes`, `dollar_changes`, `whole_root_volume`, `ohlc`, `curve`, `notional_returns`, `equity` and actual `positions`. Histories must stop at the shared engine information clock. Price increments compare the same dated instrument at both endpoints. Notional returns divide actual within-contract dollar P&L by the previous absolute contract notional; nonpositive/zero price bases are invalid, never stitched percentage returns. OHLC is a history of one fixed currently eligible dated instrument per root, including volume and instrument identity. This avoids rollover jumps but means long windows can have insufficient observations. No backfilled future membership is allowed.

Warm-up returns zero scores; missing required streams or invalid observed inputs fail explicitly. Futures risk, rounding, margins, timing, costs, participation and dated-contract P&L remain engine responsibilities. Scores are forecasts/directions, not final dollar holdings; the common risk engine can change the book's literal neutrality/weighting. Metadata states adaptations and source sections/pages. Portfolio optimisation, same-root calendar spreads and hedging overlays need separate execution/allocation specifications, not fabricated six-root forecasts.

The registry contains 20 signals and 52 default parameter dictionaries. Trend/reversal use the previous frozen risk-unit conventions; volume admission masks the exact five-bar reversal without a second demean. Channel is contrarian, not a trend breakout. Three moving averages retain a held direction until the fast/medium exit rule. KNN fits scales only on 126 matured five-bar labels; HP fits only the trailing information window at each decision and uses its latest endpoint. Neither algorithm is evidence of predictability.

`research/book-strategies.csv` preserves all 174 catalogue entries, original input needs, canonical book source, printed/PDF page, implementation mapping and blocking reason. An implemented adaptation is not a literal replication of the stock, ETF or FX-spot universe. It is not an evaluated result. Previous scratch experiments remain separate evidence with their original specifications and failures.
